# AI English Grader V2 (多模态批量批改版)

An AI-powered web tool for high school English essay grading, supporting **batch image uploads** and **handwriting recognition** directly from photos.

## ✨ 最新升级 (V2.0 Features)
- 📸 **多模态识图**：直接上传手写作文照片，调用 Kimi Vision API 自动识别英文并批改。
- 🚀 **批量处理**：支持一次性上传多张图片，自动排队批改，极大提升教师批改效率。
- 📝 **多题型支持**：适配高考应用文（15分）与读后续写（25分）。
- 📥 **一键导出**：支持将所有批改结果一键导出为 Word 文档。
